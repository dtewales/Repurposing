## Important note

Do not assume procedures transfer between WatchGuard families. Hardware architecture, boot media, BIOS behaviour, interface modules and CPU architecture can differ significantly between models.

The M4600 guide is based on a successful conversion of real hardware and records both the working path and the observed quirks.
